Govt Jobs Dashboard Fix
=======================

Problem:
- The live site was fetching /jobs/jobs-data.json.
- Nightly automation replaced the manually curated Rajasthan dashboard rows with noisy auto-scraped results from government portals.
- This made correct rows like SET 2026, CET Senior Secondary 2026, RPSC/Rajasthan entries disappear from live page.

Fix added:
1. Added jobs/manual-jobs.json
   - Keeps the verified/static dashboard rows permanently.
   - These rows are always loaded first.

2. Updated scripts/update_jobs_dashboard_data.py
   - Runs the scraper as before.
   - Filters noisy auto results such as FAQ, cut-off notices, results, answer keys, archives, closed/avoid rows.
   - Merges manual verified rows first, then appends useful auto-discovered rows.
   - Manual rows will not be removed by nightly cron.

3. Updated jobs/index.html
   - Keeps the same layout.
   - Supports the existing 'doubtful' badge class when data is loaded from JSON.

After deployment:
- Run the GitHub Action manually once.
- Check /jobs/jobs-data.json?v=random.
- The first rows should again include manually verified Rajasthan/opening rows.
