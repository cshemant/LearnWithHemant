Existing Razorpay Worker configuration
======================================

This version intentionally does NOT include these Pages Functions:

  functions/api/razorpay/order.js
  functions/api/razorpay/verify.js

Reason:
You already have a working Cloudflare Worker route:

  learnwithhemant.com/api/razorpay/*
  www.learnwithhemant.com/api/razorpay/*

The tool frontend still calls:

  /api/razorpay/order
  /api/razorpay/verify

On localhost/pages.dev, it uses:

  https://learnwithhemant.com/api/razorpay/order
  https://learnwithhemant.com/api/razorpay/verify

Required for advanced report unlock:
The existing Razorpay Worker's verify route must return an `unlock_token` for ₹99 payments.
If not, copy/update the Worker code from `razorpay-api-worker-update.js`.

Use the same REPORT_TOKEN_SECRET in:
1. Existing Razorpay Worker
2. Cloudflare Pages project for this site
