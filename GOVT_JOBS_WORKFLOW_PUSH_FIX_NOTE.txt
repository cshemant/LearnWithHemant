Govt jobs workflow push fix
===========================

Issue fixed:
The GitHub Action was able to scan and generate job data, but the final commit failed with:
"Updates were rejected because the tip of your current branch is behind its remote counterpart."

Reason:
The workflow was re-run from an older commit while the main branch already had newer commits.

Fix:
- Workflow now checks out latest main with full history.
- It syncs with origin/main before scanning.
- It commits with normal git commands.
- It pulls/rebases again before pushing, so non-fast-forward errors are avoided in normal cases.
- Concurrency is added to avoid two scheduled/manual runs fighting each other.

After uploading:
Run Actions -> Nightly Govt Jobs Dashboard Update -> Run workflow from latest main.
Do not use "Re-run jobs" on an old failed run.
